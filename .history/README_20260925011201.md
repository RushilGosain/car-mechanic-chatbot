An AI-powered car mechanic chatbot that helps users describe vehicle problems, answers rule-based follow-up questions, analyzes uploaded images when useful, generates an AI-assisted diagnosis using Google Gemini, and allows users to request a mechanic booking.

## Project Overview

The application combines a **Next.js frontend**, **Django REST Framework backend**, and **Google Gemini AI**.

The chatbot does not call Gemini for every message. The conversation flow is handled primarily by deterministic Python rules. Gemini is used where AI adds genuine value:

- Synthesizing the complete conversation into a diagnosis
- Analyzing uploaded vehicle images
- Producing probable causes, recommended repair/service action, and confidence
